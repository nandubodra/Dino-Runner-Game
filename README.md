# 🦖 DINO RUNNER GAME 

## ⚡ Futuristic Endless Runner Game Built Using HTML5 Canvas

DINO RUNNER — CYBER ERA is a fast-paced browser game with a futuristic cyberpunk theme. In this game, players control a dinosaur and try to survive by avoiding meteors and obstacles while increasing their score.

The project is built completely using HTML5, CSS3, and Vanilla JavaScript without using any external game engine or framework.

As the game progresses, the speed gradually increases, making the gameplay more challenging and exciting. The game also includes combo mechanics, double jump abilities, particle effects, animated backgrounds, neon-style UI, sound effects, and responsive fullscreen gameplay.

All graphics, animations, obstacles, particles, and visual effects are rendered using the HTML5 Canvas API.

---

## 🌌 About The Project

This project was created to explore frontend game development concepts using pure JavaScript and Canvas rendering techniques.

The game includes:
- Smooth jump physics
- Double jump system
- Collision detection
- Dynamic obstacle spawning
- Combo score system
- Lives system
- Particle effects
- Screen shake effects
- Speed progression
- Responsive design
- Procedural sound effects using Web Audio API

The visual design is inspired by retro arcade games and cyberpunk neon aesthetics.

## 🎮 Gameplay

The player controls a dinosaur that must avoid incoming obstacles and survive as long as possible. The longer the player survives, the faster the game becomes.

Players can:
- Jump
- Double Jump
- Build Combos
- Increase High Score
- Progress Through Levels
